## Confirmed defects (discovered → classified → fixed → validated)

### F-013 (MAJOR, resolved) — Chapter 14, fabricated Debug Lab traceback
`14-11-property`'s Debug Lab 6 ("забыли декоратор @radius.setter") showed code that defines a `@property` getter for `radius`, then redefines `radius` a second time as a plain method *without* `@radius.setter`, and claimed this raises `AttributeError: property 'radius' of 'Krug' object has no setter` when `krug.radius = 5` is attempted. Independently verified under Python 3.14.6 that this claim is factually wrong for the exact code shown: the second `def radius(self, value):` completely **overwrites** the property descriptor in the class namespace with a plain function — `Krug.radius` is no longer a property at all — so `krug.radius = 5` succeeds silently, creating a shadowing instance attribute (`krug.__dict__['radius'] == 5`), with no exception raised. The claimed error text only occurs for a getter-only property with *no* second `def radius` at all — a different piece of code than what was shown. Fixed by correcting the Debug Lab's terminal transcript and explanation to describe the actual, more subtle and arguably more instructive silent-failure behavior, rather than inventing a traceback that doesn't occur.

### F-014 (MINOR, resolved) — Chapter 14, truncated error text
`14-23-dataclasses`'s Debug Lab claimed a mutable dataclass field default (`tovary: list = []`) raises `ValueError: mutable default <class 'list'> for field tovary is not allowed`. Verified under Python 3.14.6 that the actual message has an additional trailing clause: `...is not allowed: use default_factory`. Corrected to the exact text.

### F-015 (MINOR, resolved) — Chapter 15, stale JSON error text
`15-25-json-serializatsiya`'s Debug Lab claimed a trailing comma before a closing JSON brace (`'{"theme": "dark",}'`) raises `json.decoder.JSONDecodeError: Expecting property name enclosed in double quotes`. Verified under Python 3.14.6 that this is stale — Python 3.13+ introduced a more specific message for this exact case: `Illegal trailing comma before end of object: line 1 column 17 (char 16)`. This is the same category of defect as Batch C's F-008a/F-008b (stale pre-3.14 error text), confirming this is a recognizable, recurring risk category across the course whenever CPython's error messages are improved in a version the course targets. Corrected to the exact, verified text.
