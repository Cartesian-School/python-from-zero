# Canonical Page Archetypes

Define and review reusable book-page archetypes here before implementing them in the canonical publication pipeline.

Initial archetypes:

- cover
- title page
- copyright/license
- about author
- introduction
- table of contents
- chapter opener
- ordinary theory page
- heading-heavy page
- code-heavy page
- callout-heavy page
- table page
- diagram/figure page
- project opener
- chapter summary
- index/reference page

Archetypes are shared across language editions. Only content/localized strings vary by language.
