# Chapter 23 — official Git/GitHub sources

Chapter 23's Git/GitHub foundation pages adapt and translate official
documentation into Russian. GitHub's docs content (github.com/github/docs)
is licensed **CC BY 4.0**; git-scm.com content is used as a link-only
factual reference, not translated wholesale. Every adaptation is a
rewritten Russian explanation built from the source, with SafeSort
substituted for GitHub's own example project where that helps continuity
— not a literal translation.

**Source of truth:** the machine-readable manifest at
[`data/chapter-23-official-sources.json`](../data/chapter-23-official-sources.json),
validated by `scripts/validate_chapter23_sources.py`. That validator
re-extracts every `official_sources(...)` call from
`scripts/build_chapter_23.py` and fails the build if the manifest's set
of URLs, licenses, or routes (chapter pages) drifts from what the chapter
actually cites — so this document can't silently go stale the way a
hand-maintained table can. This file exists as a human-readable narrative
companion; when in doubt, the JSON manifest wins.

Each adapted page also carries a small "Официальная документация" box
near its official-source citations, generated by
`site_lib.official_sources()` (see `scripts/site_lib.py`), naming the
source and stating that the text is a translation/adaptation under
CC BY 4.0 — not hidden only in this file or the manifest.

Git itself (git-scm.com) is linked, not translated — see the `git-scm`
provider entries in the manifest (currently: Git Downloads, Git for
Windows, Git for macOS).

Pro Git (the book at git-scm.com/book) is CC BY-NC-SA — not reused here
beyond linking to the official page; its explanatory prose is not the
source for this chapter's Russian text.
