# Chapter 23 — official Git/GitHub sources

Chapter 23's Git/GitHub foundation pages adapt and translate official
documentation into Russian. GitHub's docs content (github.com/github/docs)
is licensed **CC BY 4.0**; git-scm.com content is used as a link-only
factual reference, not translated wholesale. Every adaptation below is a
rewritten Russian explanation built from the source, with SafeSort
substituted for GitHub's own example project where that helps continuity
— not a literal translation.
