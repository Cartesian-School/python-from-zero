# M01 — Russian Content Audit Baseline

## Decision

The Russian curriculum frozen at commit
`929a69d13acc0e22a47eeb46c6a2146f33c7e732` is the only baseline for M01.
M01 evaluates and corrects educational content. It does not redesign visuals,
rebuild the book, or start Polish or English localization.

## Canonical-source boundaries

The curriculum has three canonical source families:

1. Theory is edited in `scripts/build_chapter_XX.py` and the supplementary page
   builders. The corresponding `site/**/*.html` files are generated review
   surfaces.
2. Practical lessons are edited in `notebooks/chapter-XX/*.ipynb`.
3. Standalone projects are declared in `manifest/projects_manifest.json` and
   edited in the referenced `projects/**` sources.

The PDF and EPUB are derived publications. They are outside M01 and must not be
used to approve source content. They will be regenerated and reviewed in M03.

## Frozen inventory

The deterministic inventory is generated by:

```bash
python scripts/build_ru_content_audit_inventory.py
```

It is stored in `manifest/ru_content_audit_inventory.json` and protected by
`tests/test_ru_content_audit_inventory.py`.

Checksums of generated HTML review surfaces are historical evidence bound to the
frozen baseline. CI may regenerate delivery HTML before running pytest, so the
determinism contract compares canonical source checksums and inventory structure
without replacing those historical review-surface checksums.

The baseline contains:

| Review unit | Count |
| --- | ---: |
| Chapters | 24 |
| Chapter openers | 24 |
| Theory lessons | 624 |
| Supplementary content units | 4 |
| Canonical practical notebooks | 493 |
| Standalone projects | 13 |
| Total independently tracked review units | 1,158 |

The previous `coverage_manifest.json` contains 294 table-of-contents entries.
Those entries are useful for book coverage, but they cannot prove that every
theory page, notebook, and project received a professorial review.

## Status semantics

Every review unit starts as `not_started`. M01 uses this vocabulary:

- `not_started`: no professorial review has been performed;
- `in_review`: review is active and evidence is incomplete;
- `needs_rework`: one or more binding findings remain unresolved;
- `reviewed`: the reviewer completed the pass, pending approval evidence;
- `approved`: all required evidence and corrections passed the M01 gate.

M01-I01 does not approve educational content. Its only purpose is to prove the
scope, freeze the baseline, and prevent silent omissions.

## Exit criteria for M01-I01

M01-I01 is complete only when:

1. all 24 theory generators and their generated review surfaces are indexed;
2. all canonical notebooks are indexed and registered in the practice manifest;
3. all declared standalone projects are indexed with checksums;
4. each unit has a stable identifier, source path, checksum, and initial status;
5. the generated inventory is deterministic and contract-tested;
6. no unit is falsely marked as reviewed or approved.

The next work item, M01-I02, defines the binding professorial review rubric and
the evidence required to move a unit through these statuses.
