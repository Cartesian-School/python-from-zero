01 / О проекте

Как устроен проект

Небольшое серверное приложение хранит задачи в SQLite, выводит их через Jinja2 и обрабатывает создание, выполнение и удаление отдельными маршрутами Flask.

Возможности

  • Постоянное хранение задач в SQLite
  • HTML-интерфейс на шаблонах Jinja2
  • Маршруты CRUD и JSON API списка задач

Что вы отработаете

  1. Связывать HTTP-маршруты с шаблонами
  2. Работать с SQLite в контексте запроса
  3. Проверять и нормализовать данные формы

02 / Локальный запуск

Запуск проекта

$python -m pip install Flask
$python projects/flask/todo-app/app.py

После запуска откройте локальный адрес, который выведет Flask.
