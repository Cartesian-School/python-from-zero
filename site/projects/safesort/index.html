SafeSort

Локальная программа командной строки для безопасной сортировки файлов и поиска дубликатов: план перемещений без изменения файлов, отмена последней операции.

CLIpathlibhashlib
Скачать README Открыть практику

01 / О проекте

Как устроен проект

Устанавливаемый CLI-пакет сначала сканирует и строит проверяемый план, а изменяет файлы только по явной команде apply. Операцию можно отменить по журналу перемещений.

Возможности

  • Раздельные команды scan, plan, apply, duplicates и undo
  • Поиск дубликатов по размеру и SHA-256 без удаления
  • Защита от перезаписи, символьных ссылок и повторной сортировки

Что вы отработаете

  1. Проектировать безопасный файловый workflow
  2. Строить CLI на argparse и pathlib
  3. Фиксировать обратимые изменения в JSON-манифесте

02 / Локальный запуск

Запуск проекта

$python -m pip install -e projects/python/safesort/
$safesort --help

Команды scan, plan и duplicates доступны для безопасного знакомства без изменения файлов.
