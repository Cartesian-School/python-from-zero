Flask, Django и FastAPI: как выбрать подход

Не «какой фреймворк лучше», а «что нужно именно этому проекту» — сравнение по задачам.

Раздел 22.17 показал общую карту. Теперь сравним три самых заметных фреймворка — Flask, Django и FastAPI — по конкретным задачам, а не по общим впечатлениям.

Что нужноFlaskDjangoFastAPI
Классический сайт с HTML-страницамиДа, через JinjaДа, через встроенные шаблоныНе основная задача — фреймворк ориентирован на API
Админ-панель для управления даннымиНет своей — можно добавить расширениемДа, встроенная автоматическаяНет своей
Приложение вокруг базы данныхЧерез сторонний ORM (раздел 22.26)Да, встроенный ORM и миграцииЧерез сторонний ORM
API-сервисДа, вручную или через расширенияДа, но обычно с отдельным пакетом Django REST FrameworkДа, это основной сценарий использования
Автоматическая документация APIНет своейНет своей в ядреДа, встроенная, через OpenAPI
Валидация входных данныхВручную или через расширенияЧерез формы и сериализаторы Django/DRFВстроенная, на основе подсказок типов Python
Структура проектаНе навязываетсяЗаданная структура приложений/проектовНе навязывается
Асинхронный интерфейс (раздел 22.19)WSGI, с ограниченной поддержкой async-обработчиковПоддерживает и WSGI, и ASGI режимы развёртыванияASGI изначально
Django REST Framework — отдельный проект, а не часть ядра Django
Django из коробки умеет отдавать HTML-страницы и имеет админ-панель, но полноценный инструментарий для REST API — это отдельный пакет, Django REST Framework (DRF), который устанавливают и подключают самостоятельно. Он не входит в состав самого Django и не устанавливается вместе с ним автоматически.

Почему в этой главе используется Flask

Для первого знакомства с серверной веб-разработкой в этой главе используется Flask. У него небольшое ядро: маршрутизация, обработка запросов и ответов, а также работа с шаблонами остаются хорошо заметны в коде. Это удобно для учебного проекта, где важно увидеть основные механизмы отдельно, не разбираясь одновременно с крупным набором готовых подсистем. Выбор Flask здесь сделан в учебных целях и не означает, что он лучше Django или FastAPI для всех задач — у каждого из них есть сценарии, где он подходит лучше.
