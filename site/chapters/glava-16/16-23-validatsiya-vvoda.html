Валидация ввода и обратная связь

Сырой текст пользователя не становится числом сам — между ними должна быть проверка.

Валидация — прежде чем считать

validate_amount.py
def validate_amount(text):
    if not text.strip():
        return False, "Поле не должно быть пустым"
    try:
        value = float(text)
    except ValueError:
        return False, "Введите число"
    if value <= 0:
        return False, "Число должно быть больше нуля"
    return True, ""

print(validate_amount(""))      # (False, ...)
print(validate_amount("abc"))   # (False, ...)
print(validate_amount("-5"))    # (False, ...)
print(validate_amount("100"))   # (True, "")

Как показать ошибку пользователю

status_label.py
ok, message = validate_amount(schet_entry.get())
if not ok:
    status_label.config(text=message, foreground="#DB2777")
    return
Ошибка — на экране, а не только в терминале
GUI-пользователь обычно не смотрит в терминал. Показывайте ошибку через виджет-статус или messagebox.showerror(...) (раздел 16.18) — печать print(...) в терминал не считается обратной связью пользователю в оконном приложении.

🔬 Чуть глубже: validatecommand

У Tkinter есть встроенный механизм валидации прямо на уровне виджета (validate=, validatecommand=, register(...)) — синтаксис у него не самый интуитивный, поэтому для большинства форм в этом курсе достаточно ручной проверки перед вычислением, как выше.
