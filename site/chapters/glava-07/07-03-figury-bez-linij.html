Глава 7 · Глубокое погружение в Turtle

Фигуры без линий

Закрашенные фигуры, готовая команда для окружностей и точки без движения черепашки.

Фигуры без линий: заливка цветом

Чтобы нарисовать не просто контур, а закрашенную фигуру, оберните рисование между begin_fill() и end_fill() — цвет заливки задаётся заранее командой fillcolor().

zalivka.py
import turtle

screen = turtle.Screen()
artist = turtle.Turtle()

artist.fillcolor("gold")
artist.begin_fill()
for _ in range(4):
    artist.forward(100)
    artist.right(90)
artist.end_fill()

screen.exitonclick()

Окружности

Рисовать окружность вручную через множество коротких отрезков не нужно — у Turtle есть готовая команда circle(радиус):

okruzhnost.py
artist.circle(60)              # окружность радиусом 60
artist.circle(-60)             # отрицательный радиус — по часовой стрелке

Точки

Мы уже видели dot() в главе 6 — маленький закрашенный кружок в текущей позиции, без движения черепашки:

tochki.py
artist.dot(20, "red")   # точка диаметром 20, красная
