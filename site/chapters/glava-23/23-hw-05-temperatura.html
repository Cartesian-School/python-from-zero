Домашний проект E: преобразование температуры

Одна функция перевода в Цельсий и обратно — и явная проверка, что такой температуры вообще может существовать.

Небольшое, но по-настоящему полезное приложение: вводим температуру, выбираем единицу через переключатели и сразу видим значение во всех трёх шкалах — Цельсий, Фаренгейт, Кельвин:

temperature_converter.py
ABSOLYUTNYJ_NOL_C = -273.15

def preobrazovat(znachenie: float, iz_edinicy: str) -> dict[str, float]:
    if iz_edinicy == "C":
        c = znachenie
    elif iz_edinicy == "F":
        c = farengejt_v_celsij(znachenie)
    else:
        c = kelvin_v_celsij(znachenie)

    if c < ABSOLYUTNYJ_NOL_C:
        raise ValueError("температура ниже абсолютного нуля")

    return {"C": c, "F": celsij_v_farengejt(c), "K": celsij_v_kelvin(c)}
-300°C не существует
Абсолютный ноль — минимально возможная температура: -273.15°C, 0 K, -459.67°F. Любое значение ниже этой границы физически невозможно, и приложение отклоняет его явной ошибкой ValueError, а не молча выдаёт формально посчитанный, но бессмысленный результат.
K, а не °K
У шкалы Кельвина нет знака градуса: правильная запись — 273.15 K, а не 273.15°K. Это не орфографическая мелочь: у Цельсия и Фаренгейта отсчёт идёт от условно выбранной точки, поэтому у них и есть «градус» в названии единицы, а кельвин отсчитывается от абсолютного нуля и исторически определён без такого смещения.

Формулы перевода остаются чистыми функциями без Tkinter, а окно создаётся только внутри main() — как и во всех остальных домашних проектах.

Полный код: projects/tkinter/temperature-converter/temperature_converter.py
