# SafeSort

Локальная программа командной строки для безопасной сортировки файлов и поиска дубликатов.

## Features

- сканирование каталога и классификация файлов по расширению
- план перемещений без изменения файлов
- перемещение файлов только по явной команде
- поиск файлов с одинаковым содержимым
- отмена последней выполненной операции

## Safety

scan, plan и duplicates только читают файловую систему. Перемещает файлы исключительно apply.

На странице проекта на GitHub иногда встречаются цветные значки (badge) вида «tests: passing» или «coverage: 98%». Такой значок честен только тогда, когда его действительно обслуживает настроенный сервис — например, GitHub Actions из раздела 23.30. Вставлять его раньше, чем он подключён к реальной проверке, значит показывать то, чего на самом деле нет.
