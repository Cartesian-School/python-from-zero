Rozdział 23: Pierwszy projekt w GitHub: SafeSort
Wymagane Python lokalne

23-16 · Cofnięcie i konflikt przy przywracaniu

Zadanie sprawdza lokalne checkout SafeSort, ścieżki systemowe, Git lub operacje na lokalnym systemie plików. Środowisko przeglądarki nie zapewnia tego samego kontekstu inżynierskiego. Uruchom Canonical laptopa w osobnym środowisku Python 3.14.

📄 Pobierz .ipynb

Środowisko reprodukowane SafeSort

git clone https://github.com/Cartesian-School/safesort.git
cd safesort
python3.14 -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install -e ".[dev]"
python -m pip install jupyter ipykernel
python -m ipykernel install --user --name safesort-py314 --display-name "SafeSort Python 3.14"
jupyter lab

Wybierz kernel SafeSort Python 3.14. Przed pracą uruchom diagnostykę:

import sys
import safesort

print(sys.executable)
print(safesort.__file__)

Pierwsza ścieżka powinna prowadzić do .venv, drugi w checkout src/safesort.

VS Code

Instalacja rozszerzeń Python oraz Jupyter (Microsoft), otwórz Pobrałem plik bezpośrednio do VS Code, wybrałem interpreter Python 3.14 i uruchom komórki (Shift+Enter) — kod zostanie wykonany w checkout SafeSort.

PyCharm

Otwórz pobrany plik w PyCharm (Professional natywnie obsługuje laptopy, w Community zainstaluj wtyczkę Jupyter), wybierz interpreter Python 3.14 i uruchamiaj komórki.

Jupyter

Set Jupyter (pip install notebook), uciekaj jupyter notebook w folderze z pobranym plikiem i otwórz go w przeglądarce — jądro wykonuje się lokalnie, więc jądro będzie używać środowiska SafeSort.
