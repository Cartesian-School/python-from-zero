Rozdział 18: Projekt: Tkinter Aplikacja do rysowania
Wymagane Python lokalne

18-04 · Pozycja myszy i linie

Ta praktyka wykorzystuje tkinter, który otwiera natywne okno graficzne Python. Ten tryb nie jest dostępny w obecnym środowisku przeglądarki Python. Zrób to ćwiczenie lokalnie w Python 3.14.

📄 Pobierz .ipynb

VS Code

Instalacja rozszerzeń Python oraz Jupyter (Microsoft), otwórz Pobrałem plik bezpośrednio do VS Code, wybrałem interpreter Python 3.14 i uruchom komórki (Shift+Enter) - Na komputerze otworzy się tkinter okna. 🎉

PyCharm

Otwórz pobrany plik w PyCharm (Professional natywnie obsługuje laptopy, w Community zainstaluj wtyczkę Jupyter), wybierz interpreter Python 3.14 i uruchamiaj komórki.

Jupyter

Set Jupyter (pip install notebook), uciekaj jupyter notebook w folderze z pobranym plikiem i otwórz go w przeglądarce — rdzeń działa lokalnie, dlatego okno tkinter otworzy się jak zwykle.
