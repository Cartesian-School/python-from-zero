Wymagane Python lokalne

23-06 · Projekt domowy F: aplikacja Notatki

Zadanie importuje dodatkowy kod projektu z repozytorium kursów i może korzystać z lokalnego podsystemu graficznego lub plikowego. Uruchom kanonicznego laptopa w osobnym środowisku Python wersji 3.14.

📄 Pobierz .ipynb

Powtarzalne środowisko projektu kursowego

git clone https://github.com/Cartesian-School/python-from-zero.git
cd python-from-zero
python3.14 -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install pytest pygame-ce jupyter ipykernel
python -m ipykernel install --user --name course-py314 --display-name "Course Python 3.14"
jupyter lab

Wybierz kernel Course Python 3.14. Na Linux Tkinter możesz potrzebować pakietu systemowego python3-tk. Sprawdź środowisko:

import sys
from pathlib import Path

print(sys.executable)
print(Path.cwd())

VS Code

Instalacja rozszerzeń Python oraz Jupyter (Microsoft), otwórz Pobrałem plik bezpośrednio do VS Code, wybrałem interpreter Python 3.14 i uruchom komórki (Shift+Enter) - Kod działa w kursie checkout.

PyCharm

Otwórz pobrany plik w PyCharm (Professional natywnie obsługuje laptopy, w Community zainstaluj wtyczkę Jupyter), wybierz interpreter Python 3.14 i uruchamiaj komórki.

Jupyter

Set Jupyter (pip install notebook), uciekaj jupyter notebook do folderu z pobranym plikiem i otwórz go W przeglądarce — rdzeń działa lokalnie, więc rdzeń korzysta ze środowiska kursu.
