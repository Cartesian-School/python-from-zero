Projekt Edukacyjny · Rozdział 23

SafeSort

Lokalne narzędzie wiersza poleceń do bezpiecznego sortowania plików i znajdowania duplikatów: planuj ruchy bez zmiany plików, cofnij ostatnią operację.

CLIpathlibhashlib
Pobierz README Otwórz staż

01 / O projekcie

Jak działa projekt

Pakiet CLI-, który jest zainstalowany, najpierw skanuje i buduje plan do sprawdzenia i zmienia pliki tylko za pomocą wyraźnego polecenia apply. Operacja może zostać anulowana z dziennika ruchu.

Cechy

  • Oddzielne polecenia scan, plan, apply, duplicates i undo
  • Wyszukiwanie duplikatów według rozmiaru i SHA-256 bez usuwania
  • Ochrona przed nadpisaniem, linkami symbolicznymi i ponownym sortowaniem

Co przećwiczysz

  1. Projektować bezpieczny plikowy workflow
  2. Buduj CLI na argparse i pathlib
  3. Zachować odwracalne zmiany w manifeście JSON-

02 / Lokalna premiera

Uruchomienie projektu

$python -m pip install -e projects/python/safesort/
$safesort --help

Polecenia scan, plan i duplicates są dostępne dla bezpiecznego znajomości bez konieczności modyfikowania plików.
