01 / O projekcie

Jak działa projekt

Mała aplikacja serwerowa przechowuje zadania w SQLite, wyświetla je przez Jinja2 i obsługuje tworzenie, wykonanie oraz usuwanie za pomocą oddzielnych tras Flask.

Cechy

  • Trwałe przechowywanie zadań w SQLite
  • HTML- interfejs na Jinja2 szablonach
  • Trasy CRUD i lista zadań JSON API

Co przećwiczysz

  1. Skojarzenie HTTP- tras z szablonami
  2. Pracować z SQLite w kontekście zapytania
  3. Sprawdzanie i normalizowanie danych formularza

02 / Lokalna premiera

Uruchomienie projektu

$python -m pip install Flask
$python projects/flask/todo-app/app.py

Po uruchomieniu otwórz lokalny adres, który wygeneruje Flask.
