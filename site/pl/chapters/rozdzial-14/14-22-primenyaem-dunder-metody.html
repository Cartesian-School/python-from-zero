Praktyka: Aplikuj __str__ i __eq__

Mała klasa Tochka to plac zabaw do utrwalania obu metod w Sekcji 14.21.

Praktyka: punkt na płaszczyźnie

Zastosuj obie metody z rozdziału 14.21 do małej klasy Tochka jest współrzędną x, y:

tochka.py
class Tochka:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

a = Tochka(1, 2)
b = Tochka(1, 2)
c = Tochka(5, 5)

print(a)          # (1, 2)
print(a == b)      # True — współrzędne się zgadzają
print(a == c)      # False
f-string i __str__ współpracują
f"Точка: {a}" powoduje to samo __str__to i print(a) – każde miejsce, gdzie Python trzeba zamienić obiekt na łańcuch znaków dla człowieka, przechodzi przez tę metodę.
★★ Zadanie samodzielne
rasstoyanie

Dodaj Tochka metodę rasstoyanie_do(self other), która zwraca odległość euklidesową do innego punktu: ((self.x - other.x) ** 2 + (self.y - other.y) ** 2) ** 0,5.
