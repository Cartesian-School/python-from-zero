Глава 6: Рисуем классные вещи с помощью Turtle
Требуется локальный Python

06-07 · Квадрат с помощью goto

Эта практика использует функциональность, недоступную в текущей браузерной среде Python (Pyodide). Выполните это упражнение локально в Python 3.14.

📄 Скачать .ipynb

VS Code

Установите расширения Python и Jupyter (Microsoft), откройте скачанный файл прямо в VS Code, выберите интерпретатор Python 3.14 и запускайте ячейки (Shift+Enter) — на вашем компьютере.

PyCharm

Откройте скачанный файл в PyCharm (Professional поддерживает ноутбуки нативно, в Community установите плагин Jupyter), выберите интерпретатор Python 3.14 и запускайте ячейки.

Jupyter

Установите Jupyter (pip install notebook), запустите jupyter notebook в папке со скачанным файлом и откройте его в браузере — ядро выполняется локально, поэтому как обычно.
