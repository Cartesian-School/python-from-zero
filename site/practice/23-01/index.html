23-01 · Домашний проект A: калькулятор с Tkinter

Задание импортирует код дополнительного проекта из репозитория курса и может использовать локальную графическую или файловую подсистему. Выполните канонический ноутбук в отдельном окружении Python 3.14.

📄 Скачать .ipynb

Воспроизводимое окружение проектов курса

git clone https://github.com/Cartesian-School/python-from-zero.git
cd python-from-zero
python3.14 -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install pytest pygame-ce jupyter ipykernel
python -m ipykernel install --user --name course-py314 --display-name "Course Python 3.14"
jupyter lab

Выберите kernel Course Python 3.14. На Linux для Tkinter может понадобиться системный пакет python3-tk. Проверьте окружение:

import sys
from pathlib import Path

print(sys.executable)
print(Path.cwd())

VS Code

Установите расширения Python и Jupyter (Microsoft), откройте скачанный файл прямо в VS Code, выберите интерпретатор Python 3.14 и запускайте ячейки (Shift+Enter) — код выполнится в checkout курса.

PyCharm

Откройте скачанный файл в PyCharm (Professional поддерживает ноутбуки нативно, в Community установите плагин Jupyter), выберите интерпретатор Python 3.14 и запускайте ячейки.

Jupyter

Установите Jupyter (pip install notebook), запустите jupyter notebook в папке со скачанным файлом и откройте его в браузере — ядро выполняется локально, поэтому ядро будет использовать окружение курса.
